AI website generation

Creates a website from a prompt.
Can refine a rough idea into a better brief.
Keeps the previous website’s brand/style when editing.
Falls back to a mock template if the AI API is unavailable.
OTP email system

Sends verification codes by email using Brevo.
Stores OTPs in memory with expiry.
Verifies or checks codes without reusing them.
Stripe payments

Creates checkout sessions for credits.
Reads payment session details back after purchase.
Vercel deployment

Uploads the generated HTML as a static site to Vercel.
GitHub publishing

Creates/updates a GitHub repo.
Pushes index.html + README.
Optionally enables GitHub Pages.
